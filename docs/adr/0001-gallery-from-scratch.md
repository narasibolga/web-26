# Gallery built from scratch instead of adopting a gallery library

The `/gallery` route renders a week-tabbed photo recap with a masonry grid, tab crossfade, and a from-scratch lightbox. We built it with `motion` (already a dependency) + CSS `columns` masonry + `next/image`, rather than adopting `react-photo-album`, `yet-another-react-lightbox`, or React Bits `Masonry`. The reasoning: every existing section of the site is hand-built Tailwind with `next/image` and `motion`, so a library would stick out stylistically and in the diff; the grid itself is trivial (CSS `columns` + `break-inside-avoid`); the only non-trivial part (animation) is already covered by `motion`; and zero new deps means no supply-chain risk or version drift. The lightbox is built from scratch for the same reason and to keep full control of the focus-trap + scroll-lock + keyboard interaction. If zoom/pinch is needed later, `yet-another-react-lightbox` can be dropped in without restructuring the grid.
